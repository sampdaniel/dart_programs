# Dart Programs

A collection of small, self-contained **Dart programs** designed to help you practice and master core Dart concepts — from basic syntax to problem-solving challenges.

---

## About This Repository
This repo contains a growing list of mini programs written in Dart.  
Each program focuses on **clean, efficient code** and explains a specific concept such as:
- Lists, Maps, and Records
- Loops and conditionals
- Functions and recursion
- String and number manipulation
- Sorting and searching logic
- Basic algorithmic problems
